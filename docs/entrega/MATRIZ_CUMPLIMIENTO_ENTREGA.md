## Datos que debe proporcionar el equipo

1. Nombres completos de integrantes y autores.
2. Afiliación, correos institucionales y ORCID.
3. Roles CRediT reales de cada autor.
4. URL pública del prototipo Figma/FigJam.
5. Enlace definitivo del repositorio y modalidad de acceso.
6. Participantes, consentimiento, tareas, tiempos, errores y respuestas SUS.
7. Evidencia audiovisual anonimizada o enlace institucional de acceso.
8. Credenciales de demostración, únicamente si son cuentas ficticias y revocables.

## Política de datos para la demostración

No usar datos reales de gestantes. Las cuentas de demostración deben contener nombres, documentos, citas, controles y contactos completamente ficticios. Las grabaciones deben ocultar credenciales, notificaciones, números telefónicos y cualquier dato que permita identificar a una persona.
